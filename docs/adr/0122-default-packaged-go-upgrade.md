# ADR 0122: select authenticated packaged Go for ordinary Go upgrades

Status: accepted implementation contract; independent public RED precedes production

Date: 2026-10-31 UTC

## Complete function

Ordinary `factory upgrade` invoked through the Go CLI selects an authenticated
packaged Go upgrader. Prepare the existing literal `v0.2.0` default without
claiming it is published. An unavailable selection refuses without project
mutation. Source bootstrap, the direct Bash adapters, stable installer pin,
asset retirement and release activation remain separate functions.

Reuse the current release acquisition, publisher verification, exact-runtime
handoff, installation inference, complete proposal, fresh consent, transaction,
retention and recovery machinery. Do not compile source, execute a legacy
upgrader, invoke Python or call a model after choosing ordinary Go delivery.
A failed Go selection never falls back to scripts or a different release.

## Selection and route ownership

Ordinary upgrade selects one explicit `--ref TAG`, then nonempty `FACTORY_REF`,
then the declared default. Unlike initialization, it does not reuse an installed
version implicitly. Refs must be exact stable Go tags at or after v0.2.0;
malformed tags, moving aliases, prereleases, duplicate refs and conflicting
selectors refuse with status 2 before tools or project mutation. Existing
explicit candidate, local, whole-installation, backup and recovery owners retain
their grammar and priority and ignore ambient release defaults.

`--dry-run` without a source operand belongs to packaged release preview.
The existing source assessment `--dry-run --source PATH` retains its strict,
read-only owner and classified results. Its malformed operands and conflicting
selection flags cannot become an acquisition path. Preserve the existing
installed restrictions of legacy assessment/recovery routes; do not authorize
an unvalidated legacy route by removing an installed guard.

Parse release selection only before the first user `--`; preserve the validated
remaining argument vector and existing native consent grammar. A bare trailing
terminator remains accepted, while positional tail operands remain invalid for
upgrade. Carry stable selection through the authenticated child handoff so
publisher prerelease metadata is checked at every selected hop.

Help is read-only and performs no acquisition or target inspection. Validate
malformed explicit selectors before help; ignore an invalid ambient ref on the
help-only path. Preserve the current root help aliases, unknown-command/Cobra
boundary and exact selected-runtime ownership rather than importing framework
commands or permissive parsing.

## Predecessor and downgrade policy

Legacy installations use their reviewed embedded baseline. For a Go predecessor,
its descriptor version is an untrusted hint. The supported before-image family
includes exact official prereleases at or after v0.2.0-0, so an authenticated
Go release candidate can advance to stable. Nonexact, unsupported and local-*
labels refuse with actionable status 2 instead of guessing a GitHub release;
keep all bytes and direct the operator to explicit local source/before-source
or the appropriate whole-installation archive route.

An exact supported official predecessor whose release is missing, deleted or
unauthenticated fails operationally with status 1. Authenticate that predecessor
before refusing an ordinary stable downgrade. A lower selected version refuses
with status 2 before a proposal, mutating admission or publication. Equal and
newer versions remain eligible; an equal release does not advance retention.
This is a negative-only policy: labels or authenticated archives never replace
the existing complete asset/descriptor custody and transaction authorization.
Explicit candidate, local and rollback downgrade semantics remain unchanged.

## Installed admission and transaction custody

An installed ordinary Go upgrade, including its no-argument form, enters the
modern owner without retaining its own shared lease before target EX admission.
Target remains the caller's Git ancestry, including installed invocation;
its target custody/pending barriers apply. Other installed commands and bridge
protocols retain normal validated origin admission; no ambient escape is added.

Preview is read-only. Apply requires the fresh full proposal digest and declared
quiescence, preserves customized/unknown data, retains inert original bytes and
modes in the existing ignored recovery store, and runs the qualified selection's
checks. Keep exact backup/rollback and compiler-free recovery behavior. Missing
consent, changed inputs, held leases and pending transitions refuse without
publication or deletion. No cache cleanup or retention rule changes belong here.

The new ordinary controller owns cancellation through bounded native child
supervision and diagnostic publication. Independently exercise a real held Git
child before signaling only the public caller, including an ordinary diagnostic
sink and one actual full inherited stderr pipe whose reader stays idle. Require
native-group reconciliation, operational status 1, preserved project/source and
unrelated data, no success summary and original borrowed writer flags. Reuse the
shared bounded output helper if a real diagnostic hang is reproduced; keep raw
inherited file streams and avoid an unrelated global output rewrite.

## Review refinement: preview advice retains ordinary delivery

Ordinary preview advice must retain stable `--ref` selection, the exact current
proposal digest, maintained quiescence and literal project inputs. Advise:
`Re-run the same Go executable from this repository with these arguments:`
followed by a fully quoted argument vector beginning `upgrade --ref TAG`.
This is explicitly arguments for the original Go caller, not a claimed complete
executable path. Do not route ordinary advice through the public installer whose
default activation is later, switch it to explicit candidate policy, or print a
private selected executable that normal cleanup removes. Preserve existing
explicit-candidate installer advice. Observe the independent public text/ref
failure before repairing this presentation boundary.

## Observed handoff refinement: cooperative cancellation and honest uncertainty

A selected Go executable is itself a native supervisor. Killing only its process
group can leave its separately owned Git/GitHub group alive and can expose a raw
negative signal status. First reproduce this through the real selected-runtime
handoff, recording caller status and both direct-group observations independently.
Use cooperative inherited supervision only for selected release/local handoffs;
ordinary native execution keeps its established immediate termination policy.

On cancellation, send TERM to the owned selected group and allow at most two
seconds of cooperation, bounded by half the existing five-second cleanup budget.
Start that single cleanup budget before TERM and reserve its remainder for
escalation, leader reap and direct-group reconciliation. Normal selected exit
plus confirmed direct-group absence can finish cooperative ownership. This is
not a transitive process-tree proof: a normal selected controller remains
responsible for its separately owned native work and any retained nested cache.

Forced escalation or any abnormal signal exit cannot establish that cooperation
completed. Return typed ownership uncertainty and preserve the parent's exact
selected inputs even when the direct group is absent and its leader reaped.
Operational cancellation/incomplete handoff returns status 1, never a raw negative
signal code. Do not guess descendant PIDs, add an acknowledgement protocol,
expand any deadline or silently change the default native kill policy. Independent
real ignored-TERM and external-SIGKILL controls must observe refusal of false
ownership confirmation before implementing this optional supervisor mode.

in three independent fixture containers. The real preview/advice case alone takes
about 70 seconds including genuine legacy initialization; several additional
criteria perform complete Go/legacy apply and rollback. Isolate this new heavy
family instead of adding it to existing near-cap hosted groups.

Add `default-upgrade`, selecting exactly the anchored full suite prefix
`^Go factory command acceptance Go default packaged upgrade( |$)`. Exclude it from
base; preserve every existing eight-group selector and their counts. The actual
nine-way registry is 3179 identities: base 2978, installation 98, release-handoff
44, historical-recipe 12, local-init 10, local-upgrade 11, local-recovery 2,
default-init 10 and default-upgrade 14. The two new internal native criteria stay
in the existing internal-package pass and do not change acceptance counts.

Preserve default/all execution of every group and failure propagation, including
new-group failure and real empty-selection rejection. Keep anchored neighbor
controls, exact disjoint/exhaustive native identities, race instrumentation,
existing heavy worker cap of two, independent JSON/JUnit reports, all source
quality stages and both OS matrix mappings. Keep existing 25-minute test and
30-minute job limits, pins and resource policies. Observe outside-in scheduler
RED against unchanged eight-group wiring before adding the ninth group.
