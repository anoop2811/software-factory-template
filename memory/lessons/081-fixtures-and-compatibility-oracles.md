# Fixtures and compatibility oracles have different retirement rules

An interpreter used to arrange a terminal or child process can be removed by
replacing that fixture. A reference interpreter used to establish supported
cross-language behavior cannot be replaced with the product implementation
without losing independent evidence.

Inventory executable uses before deleting tool provisioning. Qualify converted
fixtures with interpreter calls refused, preserving real OS controls and a
deliberate failing control rather than accepting a source-only absence claim.

Provenance: `docs/adr/0098-whole-installation-upgrade-and-rollback.md:634` and
`docs/migration/TEST_DEPENDENCIES.md`. Decision 97 records the observed native
suite changing from 15 passed/3 failed to 18 passed with Python refused on
2026-10-17. These sources retain the contract and execution evidence.
