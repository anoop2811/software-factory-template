# Recovery inventory belongs to the original image

When the current installation inventory shrinks, interpret an existing journal,
receipt and saved descriptor using the generation of its freshly qualified
original source image. A complete recognized path set is parsing evidence;
its row count is not permission to publish or prune. Keep generation selection
shared rather than changing each recovery caller's expected count separately.

Derive inventory totals from the actual role operations. A path listed as an
unrecognized retirement candidate is preserved data, not a declared retirement.
That distinction caught an incorrect active-selection count during this work.

The contract remains [ADR 0119](../../docs/adr/0119-minimal-qualified-initializer-inventory.md).
This lesson points to that contract and does not define another migration policy.
