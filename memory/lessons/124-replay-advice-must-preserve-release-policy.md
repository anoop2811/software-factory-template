# Replay advice must preserve release policy

An ordinary stable preview must not suggest applying through an explicit
candidate selector: that changes the next invocation's publisher policy.
Argument advice also needs a usable public caller after private acquisition
storage is cleaned up.

Provenance: observed 2026-10-31 UTC through the compiled public ordinary-upgrade
criterion with a real selected-image planner. The text advice first suggested
the installer and `--go-candidate` and failed; the same criterion then passed
with exact stable-ref, proposal, quiescence and literal-input arguments for the
original Go executable. The runs reported 0 passed/1 failed in 72.601 seconds
and 1 passed/0 failed in 73.065 seconds.
